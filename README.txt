Serial Number Extractor - Pull camera body and lens serial numbers from images
============
1. Insert the SD card.
2. Double-click "SN-Extractor.exe". It scans the card and lists the
   camera and lens serial number of each image (blank = none stored).

The exe can be run from anywhere and no longer depends on exiftool.

Compatible image formats: JPG, CR2, CR3, NEF, ARW, DNG
